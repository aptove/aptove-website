Frequently Asked Questions

Everything you need to know about Aptove, the open source mobile client for AI agents.

The Basics

Aptove is an open source iOS (and Android) mobile app that lets you chat with any ACP-compatible AI agent from your phone. Think of it as a universal remote control for your AI agents: you bring the agents, Aptove brings the interface.

It pairs with Aptove Bridge, a lightweight Rust binary that runs on your machine alongside your agent and exposes it over a secure WebSocket.

Agent Client Protocol (ACP) is an open standard that defines how AI agents communicate with client applications. It decouples the agent from the interface, so any ACP-compatible client (like Aptove) can talk to any ACP-compatible agent.

This means you are never locked in to a single vendor's app to access your agent.

Any agent that supports ACP or can be wrapped with an ACP-compatible bridge. Currently this includes:

  • GitHub Copilot (copilot --acp)
  • Claude (npx @agentclientprotocol/claude-agent-acp)
  • Google Gemini (gemini --experimental-acp)
  • OpenAI Codex (npx @agentclientprotocol/codex-acp)
  • Goose AI (goose acp)
  • Any custom agent that speaks ACP over stdio

See the agent setup docs for the full list and setup guides.

Why Aptove

Most AI apps are tightly coupled to a single vendor's model. If you use Claude Code, GitHub Copilot, and a custom internal agent, you end up juggling multiple apps with different UIs, notification settings, and subscriptions.

Aptove gives you one consistent interface for all of them. Add a new agent in seconds without installing a new app, and switch between agents in a single tap.

Claude.ai and ChatGPT are hosted services locked to specific models. Aptove is a client that connects to any agent you choose to run, whether that's a frontier model API, a local model, or your own custom agent running on your own machine.

Your conversations go directly between your phone and your agent via the Bridge. No third-party server sees your messages unless you explicitly configure one.

Aptove is built for people who run their own agents: coding assistants, automation pipelines, personal AI assistants running on a home server. It lets you:

  • Monitor and interact with long-running agentic tasks from your phone
  • Get push notifications when your agent finishes a task
  • Connect to agents over your local network or securely via Tailscale from anywhere
  • Run multiple agents simultaneously and switch between them instantly
  • Streaming responses: agent output appears word-by-word as it arrives
  • Markdown and code rendering: responses are rendered with syntax highlighting
  • Voice input: dictate messages using on-device speech recognition (iOS 16+, no subscription required, works offline)
  • Slash commands: type / to open a command picker for agent-defined commands
  • Multi-agent: connect to multiple bridges and switch between agents in one tap
  • Session continuity: close the app and resume your conversation later; the bridge preserves the agent session
  • Auto-reconnect: the app reconnects automatically on network changes or bridge restarts
  • Push notifications: get notified when your agent responds even when the app is backgrounded

Privacy & Security

No. Messages travel directly between your mobile app and your Bridge over an encrypted WebSocket. Aptove infrastructure never sees the content of your conversations.

The push relay (if enabled) only receives a lightweight notification trigger from your Bridge, never the content of your conversations.

Pairing is done via a one-time 6-digit code displayed on the Bridge (or scanned as a QR code). Once paired, the app stores credentials securely in the iOS Keychain.

Remote connections over Tailscale are end-to-end encrypted. Local connections are scoped to your LAN. The Bridge never exposes your agent to the public internet unless you explicitly configure it to do so.

Setup & Compatibility

An Android app is in development. The iOS app is the primary release today. Follow GitHub or join the Discord to be notified when the Android app is available.

You need to be comfortable running a terminal command to install the Bridge. After that, the Bridge has an interactive TUI that walks you through setup, and pairing is just scanning a QR code with your phone.

Connecting the agent itself requires following the guide for your specific agent (e.g., Claude Code, Copilot). See docs.aptove.com for step-by-step instructions.

On any machine where your AI agent lives: your laptop, a home server, a cloud VM, or a remote workstation. The Bridge supports macOS, Linux, and Windows.

For local connections the Bridge and your phone just need to be on the same network. For remote access, install Tailscale on both the host machine and your phone.

You can run multiple Bridge instances simultaneously, one per project folder, and each appears as a separate agent in the app.

Push notifications are optional. When enabled, the Bridge sends a notification to your phone as soon as your agent produces a response, even when the app is in the background.

This is especially useful for long-running agentic tasks: kick off a task, put your phone in your pocket, and get tapped when it's done. You can enable it with a few lines in your Bridge config or disable it entirely if you prefer.
